# 票小帮 - PDF 发票管理工具

一个纯前端的 PDF 电子发票管理工具，所有文件处理都在浏览器本地完成，不会上传到任何服务器。

**在线使用**：https://wy133656.github.io/piaoxiaobang/

---

## 功能概览

### 1. 发票台账管理（核心功能）

批量上传 PDF 发票，自动识别并生成 14 列标准台账：

| 列 | 字段 | 说明 |
|----|------|------|
| 1 | 发票类型 | 电子专票 / 电子普票 / 纸质专票 / 纸质普票 |
| 2 | 开票日期 | 格式 yyyy-MM-dd |
| 3 | 发票号码 | 20 位数电票号码或旧版发票号码 |
| 4 | 销售方名称 | 公司全称 |
| 5 | 销售方简称 | 自动从全称提取（去地域、去行业词、去公司类型后缀） |
| 6 | 购买方名称 | 公司全称 |
| 7 | 商品/项目摘要 | 提取商品分类星链（如 `*照明装置*颜色分类:白`）+ 规格型号 |
| 8 | 金额(不含税) | 合计金额（数电票）或价税合计（旧版发票兜底） |
| 9 | 税额 | 合计税额或由价税合计反算 |
| 10 | 价税合计 | 金额 + 税额自动计算 |
| 11 | 费用分类 | 按摘要/销售方关键词自动分类（建设费用/办公费/福利费等） |
| 12 | 特殊情况说明 | 按金额分级 + 类型自动生成报销附件提示 |
| 13 | 重命名后文件名 | `类型+日期+号码+简称+合计.pdf` 格式 |
| 14 | 序号 | 自动编号 + 合计行 |

**台账特性**：
- 重复发票自动标红（按发票号码 + 发票代码比对）
- 字段不完整的发票标黄提醒
- 费用分类未识别的标记"待确认"
- 每行可点击"编辑"打开 14 字段全编辑弹窗
- 弹窗内简称/说明/文件名支持"自动生成"按钮一键重算
- 金额/税额修改后价税合计自动联动
- 一键导出带样式 Excel（标题行合并、表头蓝底白字、数字千分位、边框、自动列宽）

### 2. 发票查重

- 批量上传发票，按发票号码自动比对
- 标注重复发票（红色高亮），显示重复次数
- 支持从台账一键导入查重
- 导出查重结果 Excel

### 3. 发票合并打印

- 批量上传 PDF 发票，合并到 A4 纸打印
- 支持每页 1/2/4/6/8 张排版
- 支持横向/纵向打印方向
- 可调整页面四边边距（mm）
- 可选发票边框显示
- 自动计算所需 A4 纸张数

## 如何使用

### 方式一：在线访问（推荐）

直接打开 https://wy133656.github.io/piaoxiaobang/ ，无需安装任何软件。

### 方式二：本地运行

双击 `index.html` 文件，用浏览器（推荐 Chrome / Edge）打开即可。

> 部分浏览器限制本地 `file://` 协议加载 Web Worker，如遇 PDF 解析失败，可用命令行启动本地服务器：
> ```
> node test-server.js
> ```
> 然后浏览器访问 `http://localhost:8765`

### 模块设计

**app.js**（前端控制器）：
- `extractPdfText(file)` — 按 y 坐标聚合成行（容差 3pt），行内按 x 排序，还原视觉阅读顺序
- `parseInvoiceText(rawText, fileName)` — 多格式发票字段解析（号码、日期、名称、金额、税额）
- `collectNameEntries(rawText)` — 按行提取"名称：xxx"条目，lookahead 终止词兼容多种版式
- `nameInBlock(clean, blockLabel)` — 在"购买方信息/销售方信息"块内定位名称
- UI 渲染、拖拽上传、编辑弹窗、Excel 导出、PDF 合并

**ledger.js**（规则引擎，纯函数 UMD 模块）：
- `detectInvoiceType(clean)` — 发票类型识别
- `extractSummary(rawText)` — 商品摘要提取（星链主体 + 规格型号，过滤数字明细）
- `extractShortName(full)` — 销售方简称提取（去地域/行业词/公司后缀）
- `classifyCategory(inv)` — 费用分类（6 大类关键词匹配）
- `buildRemark(inv)` — 特殊情况说明（金额分级 + 类型组合）
- `buildNewName(inv)` — 标准化文件名生成
- `buildLedgerWorkbook(ledger, title)` — 14 列带样式 Excel 工作簿构建

## PDF 解析原理

### 文本提取

pdf.js 返回的文本片段（item）顺序与视觉顺序不一致。票小帮按以下步骤还原：

1. 遍历每个文本片段，取 `transform[5]`（y 坐标）
2. 将 y 坐标差值 < 3pt 的片段归为同一行
3. 行内按 `transform[4]`（x 坐标）从左到右排序
4. 按 y 坐标降序排列各行（pdf.js 原生坐标系：y 从下到上增大）
5. 拼接为完整文本

### 名称提取（3 层策略）

| 优先级 | 策略 | 适用版式 |
|--------|------|----------|
| 1 | 块级提取：在"购买方信息/销售方信息"块内定位"名称"标签 | 数电票、新版电子票 |
| 2 | 按行提取"名称：xxx"，用"自家公司=购买方"识别 | 旧版无块标题的平铺格式 |
| 3 | 退化为首条=购买方、次条=销售方 | 个人代开等无自家公司场景 |

**lookahead 终止词**（防止名称匹配越界）：
`名称[：:]` / `统一社会信用代码` / `纳税人识别号` / `身份证号` / `开户行` / `地址` / `电话` / `金额` / `税额` / `价税合计` / `合计` / `备注` / `收款人` / `开票人` / `销售方信息` / `购买方信息` / `销售方` / `购买方` / `项目名称` / `规格型号` / `购销` / `买卖` / `方方` / `信信` / `息息` / `销\s` / `购\s`

### 金额提取（优先级）

1. `合计金额 ¥xx`（数电票不含税金额）
2. `合计 ¥xx`（数电票合计行）
3. `价税合计(小写) ¥xx`（旧版发票含税总额）
4. `价税合计 ¥xx`
5. `¥xx`（兜底取第一个金额）

### 费用分类关键词

| 分类 | 关键词示例 |
|------|-----------|
| 管理费用-业务招待费 | 餐饮、餐费、饭店、宴请、招待、食堂 |
| 管理费用-广告宣传费 | 广告、宣传、海报、横幅、展架、喷绘 |
| 管理费用-福利费 | 矿泉水、饮料、水果、零食、月饼、粽子 |
| 建设费用 | 钢管、电缆、路锥、照明、建材、五金、消防等（200+ 关键词） |
| 管理费用-办公费 | 打印机、复印纸、文具、硒鼓、墨盒、快递 |
| 管理费用-低值易耗品 | 拖把、扫把、垃圾袋、清洁剂、洗手液 |

### 特殊情况说明规则

按金额分级 + 类型组合自动生成报销附件提示：

| 条件 | 生成说明 |
|------|---------|
| 增值税专用发票 | 需附发票认证结果(抵扣联) |
| 固定资产(打印机/电脑等 ≥1000 元) | 需附资产验收单、固定资产登记表及采购合同 |
| 快递费 | 备注栏注明项目邮递资料 |
| 餐费(≥5000) | 需附菜单、就餐人员名单及业务招待事由说明 |
| 餐费(<5000) | 需附菜单、就餐人员名单 |
| 广告费 | 需附广告合同及发布证明 |
| 福利费 | 需附发放签收表/人员名单 |
| 建设物资(≥5000) | 需附采购合同、验收单及出入库单 |
| 建设物资(≥2000) | 建议附采购合同及验收单 |
| 建设物资(<1000) | 保留发票及付款凭证 |
| 办公用品(≥5000) | 需附采购清单及验收单 |
| 办公用品(<1000) | 保留发票备查 |
| 低值易耗品 | 保留发票及领用登记 |
| 小额采购(<1000) | 保留发票及付款凭证备查 |
| 购买方非本公司 | 需说明费用归属关系或提供代付说明 |

## 已知限制

1. **扫描件 PDF**：纯图片扫描的 PDF 无法提取文本，需 OCR 支持（当前版本暂不支持）
2. **OFD 格式**：不支持 OFD 发票文件（OFD 需要专用解析库）
3. **自家公司识别**：`MY_COMPANY` 硬编码为"浙江通途数科建设有限公司"，其他公司使用需修改 `ledger.js` 第 199 行
4. **摘要长度**：摘要上限 220 字符，超长自动截断
5. **简称长度**：销售方简称上限 6 字符
6. **合并打印**：每张发票只取第 1 页嵌入

### 关键技术修复

**数电票左右两栏布局解析**：
数电票的"购买方/销售方"是竖排文字，pdf.js 提取后拆成单字散落在文本行里，形成 `购 名称：A公司 销 名称：B公司` 的行。原始正则的终止词没有单独的"销"字，导致第一个名称匹配失败。修复方案是在 lookahead 终止词中增加 `销\s|购\s`（"销"/"购"后跟空格才作为分隔符，避免误伤含"销"/"购"的公司名）。

**摘要表头被过滤**：
数电票表头 `"项目名称   规格型号   单   位   数   量..."` 被 pdf.js 插入空格后长度达 55+ 字符，触发 `l.length < 50` 阈值被过滤，导致摘要提取起始位置永远找不到。修复方案是移除长度阈值，仅用关键词定位。
