# 票小帮 - PDF 发票管理工具

一个纯前端的 PDF 电子发票管理工具，所有文件处理都在浏览器本地完成，不会上传到任何服务器。

## 如何使用

直接双击 `index.html` 文件，用浏览器（推荐 Chrome / Edge）打开即可使用。

无需安装任何软件，无需注册，无需联网（首次加载后库文件会缓存）。

> 如果双击打开后页面空白或功能异常（部分浏览器限制本地文件），可用命令行进入本文件夹，运行 `node test-server.js`，然后浏览器访问 `http://localhost:8765` 即可。

## 功能介绍

### 1. 发票台账管理
- 拖拽或点击上传 PDF 发票文件（支持批量）
- 自动提取发票号码、开票日期、销售方、金额、税额等信息
- 表格展示识别结果，重复发票自动标红
- 一键导出 Excel 表格

### 2. 发票查重
- 批量上传发票，按发票号码自动比对
- 标注重复发票，显示重复次数
- 支持从台账直接导入查重
- 导出查重结果 Excel

### 3. 发票合并打印
- 批量上传 PDF 发票，合并到 A4 纸打印
- 支持每页 1/2/4/6/8 张排版
- 支持横向/纵向打印
- 可调整页面边距、显示边框

## 使用提示

- **演示数据**：点击"加载演示数据"按钮，可立即查看效果（无需真实发票）
- **真实发票**：上传数电发票 PDF 文件，系统会自动提取文本并解析字段
- **扫描件发票**：纯图片扫描的 PDF 无法提取文本，需要 OCR 支持（当前版本暂不支持）
- **文件安全**：所有处理在浏览器本地完成，关闭页面后文件即消失

## 技术栈

| 技术 | 用途 |
|------|------|
| HTML + CSS + JavaScript | 纯前端单页应用，无需后端 |
| pdf.js | PDF 文本提取 |
| pdf-lib | PDF 合并排版（浏览器端） |
| SheetJS (xlsx) | 导出 Excel 文件 |
